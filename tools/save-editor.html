Save Editor Project Liminal Gate — everything happens in this page; nothing is sent anywhere.

Stop the local server first. It keeps the whole save in memory and rewrites all of it when it persists, so an edit made while it is running will be lost. This page cannot detect a running server, so the check is yours.

1 · Load

No save loaded.
No name file — characters, items, and Companions show as bare IDs.

Setup writes user-data/names.json when you pass --dummy-dll-dir, decoding character, item, and Companion names from your own copy of the game. None ships here: it is game text, and that directory is ignored by Git so it stays out of the repository.

2 · Account

Chapter and section are decoded from progressCode; its other bits are preserved untouched.

3 · Wallet

Energy is the premium currency (paid and free are one balance in the client). The ceilings are the client's own maxCoins and maxEnergy; the nested valuables projection is kept in step automatically.

4 · Characters

IDJobLevelProgressionSkill boost

Level and progression are the two halves of one packed value and are repacked on export. A character removed here is also removed from every party slot naming it. An added one copies the field shape of a character the account already has, so it matches whatever the client wrote, and starts with no progression, no skill boost, and no job slots filled.

5 · Companions

IIDCompanionLevelCapEXPEquipped to

A blank level means the Companion's own cap. Level and EXP are written together from the server's progression curve, because the server recomputes the level from the EXP on the next strengthen. The same Companion may be held more than once. Removing one also frees the character carrying it and empties every versus slot naming it. The box holds at most 1000; "Add one of each" grants every master the account does not yet hold, at its cap, until the box is full.

That validates it again in Python, keeps a timestamped backup, and refuses to write while a server holds the save.
